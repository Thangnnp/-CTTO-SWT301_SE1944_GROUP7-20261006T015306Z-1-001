# Research Question – LLM for Automated Acceptance Test Case & Unit Test Case Generation
**Thành viên:** Phùng Thanh Nhân

## Topic 1 – Acceptance Test Case Generation

**RQ1:** "GPT-4o zero-shot có sinh được các kịch bản Acceptance Test Case dạng văn bản tự nhiên (Natural Language) từ user stories định dạng Connextra đạt độ tương đồng ngữ nghĩa semantic similarity $\ge 0.85$ so với kịch bản viết tay bởi expert không?"

**PICO:**

| Thành phần | Nội dung |
|------------|----------|
| **P – Population** | User stories định dạng Connextra ("As a… I want… So that…") |
| **I – Intervention** | GPT-4o zero-shot sinh Acceptance Test Case truyền thống (Các bước thực hiện, Dữ liệu đầu vào, Kết quả mong đợi) |
| **C – Comparison** | Kịch bản Acceptance Test Case được thiết kế thủ công bởi Expert |
| **O – Outcome 1** | Semantic similarity $\ge 0.85$ (Cosine Similarity dựa trên không gian vector embedding) |
| **O – Outcome 2** | Executable syntax rate (Tỷ lệ cấu trúc kiểm thử hợp lệ, rõ ràng, không lỗi logic định dạng) |

## Topic 2 – Unit Test Case Generation

**RQ2:** "GPT-4 tự động sinh unit test cases cho Java/Python functions ở cyclomatic complexity trung bình có đạt branch coverage $\ge 80\%$ và mutation score $\ge 60\%$ so với test cases viết thủ công bởi sinh viên không?"

**PICO:**

| Thành phần | Nội dung |
|------------|----------|
| **P – Population** | Java/Python functions ở cyclomatic complexity trung bình (từ 3 đến 7) |
| **I – Intervention** | GPT-4 tự động sinh mã nguồn unit test cases |
| **C – Comparison** | Bộ mã unit test do sinh viên viết tay độc lập |
| **O – Outcome 1** | Branch coverage $\ge 80\%$ |
| **O – Outcome 2** | Mutation score $\ge 60\%$ |
