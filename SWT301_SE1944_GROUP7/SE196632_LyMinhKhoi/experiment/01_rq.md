# Research Question - TOPIC 2: Unit Test Case Generation

## ## RQ chính thức
[P: 3,909 Python functions từ benchmark ULT và 600 Python+Java functions], [I: Can thiệp bằng mô hình GPT-4 kết hợp chiến lược sinh test tự động (Fixturize/MUTGEN)] có đạt [O: Độ bao phủ nhánh (Branch coverage) ≥ 30.22% và tỷ lệ vượt qua kịch bản kiểm thử (Pass rate) ≥ 43%] [C: so với threshold truyền thống hoặc mô hình baseline GPT-3.5/LLaMA] không?

## ## PICO
- **P (Population):** Hệ thống mã nguồn bao gồm các hàm chức năng thuộc ngôn ngữ lập trình Java và Python trích xuất từ tập dữ liệu thực nghiệm quy mô lớn (Dataset: ULT với 3,909 Python functions, 60B+ tokens mã nguồn và 600 hàm phức tạp đa ngôn ngữ).
- **I (Intervention):** Kỹ thuật sinh mã kiểm thử tự động (Unit Test Case Generation) sử dụng các mô hình ngôn ngữ lớn tiên tiến (Mô hình can thiệp chính: GPT-4, GPT-4o kết hợp công cụ chuyên dụng Fixturize/MUTGEN) chạy cấu hình Few-shot Prompting kèm vòng lặp tự sửa lỗi biên dịch.
- **C (Comparison):** So sánh trực tiếp với công cụ sinh test case truyền thống dựa trên thuật toán tìm kiếm (EvoSuite / Randoop) hoặc các mô hình mã nguồn mở thế hệ cũ đóng vai trò Baseline (GPT-3.5, LLaMA, Llama3-70B).
- **O (Outcome):** Chỉ số đánh giá chất lượng bộ kiểm thử đầu ra đo lường thông qua: Độ bao phủ nhánh (Branch coverage đạt mức tăng trưởng vượt ngưỡng kỳ vọng >24.08%), Điểm kiểm thử đột biến (Mutation score diệt các biến thể đột biến) và Tỷ lệ bộ test thực thi thành công (Suite Pass Rate từ baseline 18% cải thiện lên 43%).
